# Pattern: Lawful Learning Seven Governance Invariants

**Topic:** `lawful-learning`  
**Pattern ID:** `LL-P-001`  
**Status:** Phase 7 research capture

## Thesis

Lawful learning prevents epistemic collapse by separating mathematical, typological, speculative, empirical, and governance claims, then enforcing the separation through explicit invariants, schemas, fixtures, and a structural checker.

## Failure mode / principle

The failure mode is silent promotion: a speculative, typological, or governance statement is treated as a mathematical or empirical result because prose collapses distinct registers into one persuasive narrative. Lawful learning prevents that failure by forcing each claim to carry an epistemic tag and by making key structural promises checkable.

## Conditions

This pattern appears when a learning system combines:

- abstract mathematical structures;
- neural or agentic implementation proposals;
- governance and publication claims;
- frontier hypotheses;
- evidence receipts and replay seals;
- mixed-register documentation.

## Symptoms

Without this pattern, the system tends to show:

- speculative formulas presented as implemented quantities;
- monitor analogies presented as predictive guarantees;
- circuit declarations without discovery or ablation evidence;
- compositions that inspect latent state while claiming black-boxability;
- replay claims that require rerunning constituents;
- claims promoted without evidence trails.

## Countermeasures

The seven governance invariants provide the operational countermeasures:

1. **May-Wigner stability monitor** — requires a declared stability monitor while preserving the typological boundary of the random-matrix analogy.
2. **Control-plane / data-plane separation** — requires explicit separation between routing/admission logic and computation/output flow.
3. **Tail-integral audit allocation** — requires explicit tail-risk audit allocation beyond expected-case coverage.
4. **Emergent-discretization discipline** — requires logged replay-sealed records for grokking, phase transitions, feature splitting, and loss-cliff events.
5. **Composition-superposition allocation** — requires circuit declarations to state whether the behavior is modeled as composition, superposition, mixed, or unknown.
6. **Anti-satisficing continuation** — prevents a run from halting merely because a sufficient condition has been met.
7. **Epistemic non-collapse** — requires every claim to preserve its M/T/S/E/G tag discipline.
