# Descriptive Ontology: Topic-Driven Research (TDR)

We separate:

1) **Repository ontology** (machine schema): classes/properties for Source/Quote/Claim/Pattern/Artifact.  
2) **Descriptive ontology** (research semantics): how we narrate and relate topics, patterns, and lessons.

## Descriptive axes (initial)

- **Scale shock** (e.g., Eternal September)
- **Governance bandwidth** (e.g., bikeshedding)
- **Interoperability vs safety** (e.g., robustness principle)
- **Legitimacy & process** (e.g., rough consensus + running code)
- **Adoption dynamics** (e.g., worse is better)
- **Institutional struggle** (e.g., protocol wars)
- **Discourse drift** (e.g., Godwin’s Law)
- **Cultural cohesion** (e.g., RFC humor, folklore)

## Output artifacts

- Pattern pages in `kb/patterns/`
- Crosswalk matrices in `matrix/`
- Timeline spine in `timeline/`
- Claims in `kb/claims/` with source links
